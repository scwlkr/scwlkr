# Domain Docs

This repository uses a single-context domain-document layout.

## Before exploring

- Read `CONTEXT.md` at the repository root when it exists.
- Read relevant ADRs under `docs/adr/` when they exist.
- If either location is absent, proceed silently.

## Vocabulary

Use domain terms as defined in `CONTEXT.md`. Do not replace established terms with synonyms.

## ADR conflicts

Surface any conflict with an existing ADR rather than silently overriding it.
